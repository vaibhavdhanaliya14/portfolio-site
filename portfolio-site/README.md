# Developer Portfolio Site

Static multi-page developer portfolio website built using HTML5, CSS3 (Grid & Flexbox), and JavaScript.

## Setup & Local Execution
1. Clone the repository: `git clone https://github.com/username/portfolio-site.git`
2. Open `index.html` directly in your browser or run via Live Server in VS Code.

## Deployment Options
- **GitHub Pages:** Push to `main` branch, enable GitHub Pages in Repository Settings -> Pages.
- **Netlify:** Drag and drop the root folder into Netlify Drop or link GitHub repo.
